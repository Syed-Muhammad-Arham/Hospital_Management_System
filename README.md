# 🏥 Hospital Management System (MediDash)

A full-stack web application designed to streamline hospital operations, manage patient records, handle doctor appointments, and secure user authentication.

## 🚀 Features

- **User Authentication:** Secure Login and Signup system.
- **Patient Management:** Add, view, update, and delete patient records.
- **Doctor Scheduling:** Manage doctor profiles and availability.
- **Database Integration:** Connected with MongoDB Atlas for real-time data storage.

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, Tailwind CSS / Framer Motion
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas

## ⚙️ Installation & Setup (Local)

1. Clone the repository:

   ```bash
   git clone [https://github.com/Syed-Muhammad-Arham/Hospital_Management_System.git](https://github.com/Syed-Muhammad-Arham/Hospital_Management_System.git)

   ```

2. Setup Backend:
   .Navigate to the server folder:
   cd src/server
   .Install dependencies:
   npm install
   .Start the backend server:
   node ser.js
3. Setup Frontend:
   .Open a new terminal and go to the root folder.
   .Install dependencies:
   npm install
   .Run the development server:
   npm run dev
